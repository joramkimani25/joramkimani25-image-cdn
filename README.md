# Image CDN

This repository serves as an image CDN (Content Delivery Network) to make images accessible online.

## Hosted Image

The image is accessible at the following URLs:

### GitHub Pages
```
https://joramkimani25.github.io/joramkimani25-image-cdn/image1.png
```

### Raw GitHub URL
```
https://raw.githubusercontent.com/joramkimani25/joramkimani25-image-cdn/main/image1.png
```

## Usage

### HTML
```html
<img src="https://joramkimani25.github.io/joramkimani25-image-cdn/image1.png" alt="Descriptive text for your image">
```

### Markdown
```markdown
![Descriptive text for your image](https://joramkimani25.github.io/joramkimani25-image-cdn/image1.png)
```

### Direct Link
You can also view the image gallery at: [https://joramkimani25.github.io/joramkimani25-image-cdn/](https://joramkimani25.github.io/joramkimani25-image-cdn/)

## Setup

To enable GitHub Pages:
1. Go to your repository settings
2. Navigate to "Pages" section
3. Under "Source", select the branch (usually `main` or `master`)
4. Select the root folder (`/`)
5. Click Save

Your images will be accessible within a few minutes!

## Adding More Images

To add more images:
1. Upload your image files to this repository
2. Rename files to avoid spaces (use hyphens or underscores)
3. Reference them using the URLs above, replacing `image1.png` with your filename

Example:
```
https://joramkimani25.github.io/joramkimani25-image-cdn/your-image.png
```
